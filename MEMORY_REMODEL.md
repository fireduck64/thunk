I think we have been thinking about memory wrong.

I don't want to over anthropromophise, but lacking a better example we can use how humans seem to work.

When a human experiences an event, they don't think "let me see if this triggers a memory" which in our system
would be doing a search.  That is automatic for humans.

Event: I see a butterfly near a castle
Triggered memory: I recall something about the butterflies city in Shadows of the Apt series.

Automatic retreival:

So for whatever our events are, like a chat message or a section of a book just read, we can automatically do a search and include those alone with that in the data sent to the agent.

Automatic vs manual:

The automatic should cover things the agent has experiences.  This means its memory log, notes it has made, memory things it is explicitely saved.  It should not automatically search the knowledge database. That information has not been internalized, it hasn't been processed by the agent.  It is outside and it should be a decision for the agent to check
that or not.

Automatic recording:

Maybe all log entires should automatically go into a vector memory store.  Humans don't need to think about remembering something, it just happens.  Maybe the search results should weight more recent entries much stronger but still the saving is automatic.

However, there should be some limits on that automatic recording.  For example, in the above butterfly castle example, the memory log should include the event, "I see a butterfly near a castle" it shouldn't include the memory automatically retreaved.  Maybe.
